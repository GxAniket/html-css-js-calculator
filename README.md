## 📖 Project Overview

The **Modern Calculator Web App** is a responsive and interactive calculator built using **HTML, CSS, and JavaScript**.

This project demonstrates core front-end development concepts including DOM manipulation, event handling, responsive design, keyboard interaction, and clean user interface implementation.

The calculator performs essential arithmetic operations while providing a smooth and intuitive user experience across desktop and mobile devices.

---

## ✨ Key Features

### 🎯 Core Functionalities

* Addition, Subtraction, Multiplication, and Division
* Real-time calculation processing
* Keyboard input support
* Clear and Delete operations
* Error handling for invalid expressions

### 🎨 User Experience

* Modern Dark-Themed Interface
* Responsive Layout
* Smooth Button Interactions
* Mobile-Friendly Design
* Clean and Minimal UI

### ⚡ Performance

* Lightweight Application
* Fast Response Time
* Pure Vanilla JavaScript
* No External Dependencies
